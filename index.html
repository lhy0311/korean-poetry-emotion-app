시의 결

시를 한 권 꺼내면 감정 사전과 문학적 해석이 함께 읽은 정서를 보여 줍니다. 감정 비율, 행별 흐름, 시어–정서–주제 다이어그램, 감정 이미지, 비슷한 시 추천까지 한 화면에서 볼 수 있습니다.

해석 중심사전 중심
최종 점수 = 해석 기반 프로필 × (1−w) + 감정 사전 점수 × w

01감정 프로필

8대 정서, 비율(%) · 실선: 선택한 시, 점선: 추천 1위 시

02행별 감정 흐름

가로축: 행 번호 · 세로축: 그 행에서 감지된 시어 수

03최종 분석 다이어그램

핵심 시어 → 정서 → 주제로 이어지는 구조

04감정 이미지

분석한 감정과 시의 소재로 그림을 만듭니다

그림의 구성

    계정이나 설치 없이 브라우저가 직접 그립니다. 감정 비율은 색의 양을, 시에 나온 소재(달·별·꽃·길·물 등)는 화면의 사물을 정합니다. '다시 그리기'를 누를 때마다 구도가 바뀝니다.

    Gemini 등에서 만든 그림을 '이미지 불러오기'로 가져오면 이 자리에 나타납니다.

    외부 AI로 만들기 (무료 Google 계정)

    1. '프롬프트 복사 후 Gemini 열기'를 누릅니다.
    2. 새 탭의 입력창에 붙여넣고(Ctrl+V) 보냅니다.
    3. 만들어진 그림을 내려받은 뒤 '이미지 불러오기'로 이 자리에 가져와 수묵화 탭과 비교합니다.

    ChatGPT나 Microsoft Designer 등 다른 AI에 붙여 넣어도 됩니다. 이 앱에는 API 키가 없고, 이미지는 사용자의 브라우저에서만 표시됩니다.

    05비슷한 감성의 시

    감정 벡터 코사인 유사도 기준 상위 3편

    06감성 지도

    감정 벡터를 2차원으로 투영(PCA)

    07전체 비교

    시 × 정서 비율(%) · 시 이름을 누르면 이동

    내 시 분석하기

    직접 입력한 시는 감정 사전으로만 분석하고, 15편 중 가장 비슷한 시를 추천합니다.
