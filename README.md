# 시의 결 — 한국 시 감정 분석 웹앱

감성컴퓨팅 2026학년도 2학기 과제용 정적 웹앱입니다. 한국 근대시 15편을 감정 사전과 해석 기반 정서 프로필로 분석하고, 작품별 감정 비율·행별 감정 흐름·유사 작품을 시각화합니다.

## 1. 웹앱 주소와 사용법

- **웹앱 주소:** https://lhy0311.github.io/korean-poetry-emotion-app/
- **저장소 주소:** https://github.com/lhy0311/korean-poetry-emotion-app

### 사용법

1. 페이지 상단의 **책장**에서 작품 제목을 눌러 시를 선택합니다. 휴대폰에서는 책장을 좌우로 밀어 다른 작품을 고를 수 있습니다.
2. 선택한 작품의 본문과 감정 요약을 확인합니다. 감정 사전과 일치한 시어는 정서별 색으로 표시됩니다.
3. **감정 사전 반영 비율** 슬라이더를 움직여 해석 프로필 중심 분석과 감정 사전 중심 분석의 차이를 살펴봅니다. 왼쪽은 해석 중심(0%), 오른쪽은 사전 중심(100%)입니다.
4. 아래의 감정 프로필, 행별 감정 흐름, 시어–정서–주제 다이어그램, 비슷한 감성의 시, 감성 지도와 전체 비교를 차례로 확인합니다.
5. **감정 이미지** 영역에는 두 탭이 있습니다.
   - **감정 수묵화:** 브라우저가 감정 비율과 작품 소재를 이용해 그림을 만듭니다. `다시 그리기`로 구도를 바꾸고 `PNG로 저장`으로 저장할 수 있습니다.
   - **AI 이미지:** `프롬프트 복사 후 Gemini 열기`를 누르고 새 탭의 생성 도구에 붙여 넣습니다. 생성한 이미지를 내려받아 `이미지 불러오기`로 앱에 넣어 수묵화와 비교합니다. 이 과정은 외부 AI 서비스에서 진행되며 앱에 API 키를 입력하지 않습니다.
6. **내 시 분석하기**에서 제목과 본문을 입력하면 감정 사전으로 분석하고 수록 작품 중 비슷한 감성의 시를 추천합니다.

별도 설치나 서버 없이 `index.html`을 브라우저에서 열어 실행할 수 있습니다. GitHub Pages 배포 시에는 저장소의 `Settings → Pages`에서 `main` 브랜치와 `/ (root)`를 선택합니다.

## 4. 분석 방법

감정 범주마다 12~16개의 어간 시어를 등록한 감정 사전 방식(A)을 사용합니다. `engine.js`의 `LEX`는 8개 감정 범주(총 106개 시어)로 구성되어 있으며, 긴 시어를 먼저 일치시키는 단일 정규식으로 행별 감정 시어 등장 횟수와 전체 감정 비율을 계산합니다. 기본 근대시 어휘에 더해 새로 수록한 5편(「빼앗긴 들에도 봄은 오는가」, 「절정」, 「거울」, 「사슴」, 「남으로 창을 내겠소」)의 핵심 맥락을 반영할 수 있도록 `빼앗`, `짓밟`, `무지개`, `마침내`, `거울`, `한가`, `고즈넉` 등의 시어를 포함해 사전을 직접 구성·정비했습니다.

각 작품에는 문학적 해석을 바탕으로 정서 강도(`profile`, 0~1)를 별도로 입력했습니다. 최종 감정 벡터는 정규화한 해석 프로필과 감정 사전 비율을 슬라이더 가중치 `w`로 결합합니다.

`최종 벡터 = normalize((1 - w) × 해석 프로필 + w × 감정 사전 비율)`

기본 가중치는 `0.4`이며, `w = 0`이면 해석 프로필만, `w = 1`이면 감정 사전만 반영합니다.

## 5. 검증 사례 3개

`node verify.js`로 15편의 해석 프로필(`w=0`)과 감정 사전 단독 결과(`w=1`)를 비교해 계산 결과와 문학적 해석이 어긋난 사례 3가지를 정리했습니다. 전체 출력은 [`verify_results.txt`](verify_results.txt)에 기록했습니다.

1. **「사슴」 — 한글 활용형·핵심 시어 누락으로 인한 사전 미탐지**  
   `w=0`에서 지배 정서는 그리움(슬픔 2위)이지만, 사전만 적용한 `w=1`에서는 감지 시어가 0건으로 나타납니다. 본문에 `슬픈`이 두 번 나오는데도 `LEX.sad`에는 어간 `슬프`만 등록되어 있어, 받침 `ㄴ`이 결합한 완성형 글자(`슬픈`)를 단순 정규식 문자열 일치로 찾지 못한 것이 첫 번째 원인입니다. 또한 `향수`, `전설`, `먼데 산` 같은 핵심 시어가 사전에 등록되지 않았습니다. 형태소 분석으로 원형(`슬프다`)을 복원하거나 `슬픈` 같은 주요 활용형과 작품 핵심어를 사전에 보강하면 미탐지를 줄일 수 있습니다.

2. **「빼앗긴 들에도 봄은 오는가」 — 문맥과 개별 단어 감정의 불일치**  
   `w=0`에서는 원망·미움과 슬픔이 중심이지만 `w=1`에서는 평온·달관(38%), 기쁨(19%), 희망·의지(19%)가 높게 계산됩니다. `푸른`, `하늘`, `봄`, `웃` 같은 자연·계절 어휘를 개별 단어 단위로만 집계하면서, "빼앗긴 들"이라는 식민지 상실의 역설적 맥락이 반영되지 않았기 때문입니다. 자연 묘사 어휘에 일괄적으로 긍정 점수를 주기보다, 주변 부정·상실 표현(`빼앗겨`, `설음`)과의 공기(co-occurrence)나 문장 단위 문맥을 반영하는 분석 모델로 개선해야 합니다.

3. **「거울」 — 어간 부분 문자열 매칭으로 인한 오탐**  
   사전 분석에서 `외로된 사업`의 `외로`가 슬픔 시어(`외롭다` 어간)로 잡힙니다. 여기서 `외로된`은 '혼자서 하는 / 빗나간' 뜻을 지닌 옛 표현에 가까워 현대어 `외로움`과 같은 정서로 단정하기 어렵습니다. 단순 부분 문자열 검색 대신 어절·형태소 경계를 확인하고, 근대시 고어·예외 표현 목록(불용어·제외 규칙)을 두어 오탐을 걸러내야 합니다.

## 6. 한계와 개선 방향

- 단어 사전은 비유·반어·상징·역사적 맥락을 충분히 읽지 못합니다.
- 짧은 어간과 부분 문자열 매칭으로 오탐이 발생할 수 있고, 활용형·시적 표현을 놓쳐 미탐이 발생할 수 있습니다.
- 해석 프로필의 점수는 작품에 대한 해석을 수치로 옮긴 것이며 객관적인 정답이 아닙니다.
- 개선 방향으로 형태소 분석, 문맥을 고려하는 언어 모델, 사전의 오탐·미탐 검토, 복수 평가자의 해석 비교를 생각할 수 있습니다.

## 7. AI 도구 사용 내역

- **Claude:** 웹앱 초기 코드 구조, UI 스타일(`style.css`), 감정 수묵화 캔버스(`art.js`), 차트 렌더링(`charts.js`), 감정 사전 초안 및 검증 스크립트(`verify.js`) 작성에 활용했습니다.
- **ChatGPT:** 과제 지시서·기술명세서 기준 대조, 작품별 해석·정서 프로필 초안 점검, 원문 행·연 및 `key` 일치 여부 검증, 출처표와 README 구조 정리에 활용했습니다.
- **직접 검토 및 수정:** 15편 원문을 각 출처와 대조해 확인했고, 작품별 해석 문장·정서 비율·검증 사례를 직접 읽고 검토·수정했으며, 다이어그램 텍스트 잘림 버그를 수정한 뒤 PC와 모바일 환경에서 전체 기능을 테스트했습니다.

## 8. 저작권 기준

수록 작품 15편은 모두 1962년 이전에 사망한 시인의 작품으로 선정해 과제 지시서의 저작권 기준을 준수했습니다. 작품별 본문 대조 출처와 서지 정보는 [`SOURCES.md`](SOURCES.md)와 웹앱 하단 출처 표에 함께 명시했습니다.

## 9. 실행 및 테스트

- **지원 브라우저:** 최신 Chrome, Edge, Safari
